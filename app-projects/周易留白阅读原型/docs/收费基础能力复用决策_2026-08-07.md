## 候选与决策

| 候选 | 许可/维护 | 适配 | 决策 |
| --- | --- | --- | --- |
| [Apple StoreKit 2 与 Xcode 本地测试](https://developer.apple.com/documentation/xcode/setting-up-storekit-testing-in-xcode/) | Apple 平台 API，随 Xcode/iOS 维护 | 原生交易验证、恢复、本地商品最合适 | **使用**；不引入第三方 IAP SDK |
| [Apple FileDocument / fileExporter](https://developer.apple.com/documentation/swiftui/filedocument) | Apple 平台 API，持续维护 | 适合未来纯 SwiftUI 数据层 | **借鉴边界，本轮不直接依赖**；当前历史位于 WKWebView，使用用户主动 Web Share/文件导入，不做两套数据源 |
| [PaywallKit](https://github.com/aligutierrez/PaywallKit) | MIT，iOS 17+，新项目、维护历史较短 | 零依赖包装较薄，但本轮引入仍增加审计面 | **不依赖，只借鉴小状态层思路**；依 Apple API 自建最小封装 |
| [Flutter packages StoreKit 示例配置](https://github.com/flutter/packages) | BSD-3-Clause，Flutter 团队活跃维护 | `.storekit` JSON 可用于交叉核对，Dart 层不适配 SwiftUI | **只核对配置结构**，不复制 Dart 代码 |
| James Legge 1882 + Internet Archive / Sacred Texts | 1882 底本是公版候选；Sacred Texts 数字转录页附非商用条件 | 内容方向适配，但数字转录不能直接进未来收费 App | **本轮不内置正文**；只登记版本与来源，待从 1882 扫描独立校录或获得商用兼容转录 |

## 自研差异

- 历史数据是小型、私密、离线的领域模型；用约 200 行可测的 Codable-风格 JSON schema 比引入数据库/同步 SDK 更可控。
- 付费状态不参与起卦、概率或结果生成，仅对未来功能权益分类。
- 英文完整译读宁可标注内容受阻，也不用机器翻译或未经许可的现代译本补位。
