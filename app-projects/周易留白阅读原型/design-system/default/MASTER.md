# 周易反思仪式设计系统：静默卦室

> 本文件是产品视觉与 UX 的主规则。页面专项规则位于 `pages/`，发生冲突时页面规则优先。
>
> 形成方式：竞品视觉取证 + `ui-ux-pro-max` 设计系统检索后人工校正。不是对任何单一竞品的复刻。

## 1. 产品表达

**一句话视觉定位：** 一个从夜墨进入纸面的私人阅读仪式；准确的卦象和可追溯的经典是主角，界面不替用户宣布答案。

**设计母题：** 夜墨、纸面、断与连、上下卦、余白、微弱天光。

**情绪顺序：** 未知 → 参与 → 显现 → 阅读 → 留白 → 日后回看。

**设计参数：** 差异度 6/10；动效 4/10；密度 3/10。移动端优先。

## 2. 不可复制与不可采用

- 不使用羊皮纸、竹简、祥云、太极背景、龙纹或假书法制造“东方感”。
- 不使用紫色宇宙、星云、霓虹光晕或塔罗卡牌墙。
- 不使用大面积玻璃拟态；透明层只用于真正的模态遮罩。
- 不使用“神谕已回答”“宇宙告诉你”等权威口吻。
- 不把六十四卦做成拥挤工具表，也不把首页变成综合玄学入口。
- 不用未经许可的现代译本、竞品插画、品牌文案、图标或界面布局。

## 3. 颜色：夜墨与暖纸

### 夜墨场景

用于起始、手动起卦和阅读之间的停顿。

| 语义 | 色值 | 用途 |
|---|---|---|
| `night-deep` | `#10120F` | 主背景 |
| `night-surface` | `#181B17` | 次级表面 |
| `night-elevated` | `#22251F` | 浮层、选中状态 |
| `text-on-night` | `#F2EEE3` | 主文本，16.24:1 |
| `muted-on-night` | `#B9B5AA` | 次文本，9.19:1 |
| `bronze` | `#C7A968` | 唯一品牌强调色，8.34:1 |

### 暖纸场景

用于经典正文、来源、译意和事后回看。

| 语义 | 色值 | 用途 |
|---|---|---|
| `paper` | `#F5F1E8` | 阅读背景 |
| `paper-raised` | `#FBF8F1` | 引文、注释表面 |
| `ink` | `#1D211C` | 主文本，14.48:1 |
| `ink-muted` | `#5D625A` | 次文本，5.54:1 |
| `paper-rule` | `#D8D1C2` | 分隔线 |
| `bronze-dark` | `#715D31` | 纸面强调与链接 |

### 状态色

- 危险与删除：`#A13E36`，仅用于真正危险动作。
- 焦点环：夜墨使用 `#E0C47C`，暖纸使用 `#715D31`，2–4px 且不移除。
- 变爻不能只靠金色表示，必须同时使用圆点、文字或线型说明。

## 4. 字体与排版

### 中文优先原型

- 经典原文：`Songti SC` / `STSong` / `Noto Serif SC`，400–500。
- 产品标题与卦名：同一宋体体系，避免假书法字体。
- UI、来源、标签：`PingFang SC` / `Noto Sans SC` / system sans，400–600。
- 数字、卦序与时间：system sans 的 tabular figures；不额外引入技术感等宽字体。

### 英语本土化候选

- 标题：`Newsreader`，不是奢侈品式高对比 Didone。
- 长文：`Source Serif 4`。
- UI：system sans。

### 字级

| 角色 | 手机 | 说明 |
|---|---:|---|
| 卦名 / 场景标题 | 36–48 | 一屏只出现一个主标题 |
| 经典原文 | 26–34 | 行高 1.55–1.7 |
| 现代译意 | 18–21 | 行高 1.65–1.8 |
| 正文 / 说明 | ≥16 | 禁止以 12px 灰字承载关键信息 |
| 标签 / 来源 | 13–14 | 字距不超过 0.08em |

正文手机每行约 20–28 个汉字，桌面正文宽度不超过 42rem。

## 5. 形状、图标与卦象

- 主视觉不是通用图标，而是准确、数据驱动的六爻结构。
- 六爻默认自下而上编号；界面绘制仍按视觉从上到下显示 6→1。
- 上下卦必须有可辨分隔，并同时标明符号、卦名与象：如“上巽☴·风 / 下兑☱·泽”。
- 变爻使用“圆点 + 第几爻文字”，不得只用颜色。
- 系统动作统一采用 Phosphor outline，默认 24pt、1.5px 笔画；品牌卦象不用第三方图标替代。
- 方向卡、输入框等高频触控面使用 10–14px 柔和圆角；正文引用块保持 0–4px。避免所有控件都是单线直角框，也不使用随意的 20–24px SaaS 大圆角。
- 首页控件通过“微弱墨面 + 细铜边 + 克制内高光”建立器物感；选中状态增加表面亮度与边线，不只改变文字颜色。
- 阴影仅用于真正浮起的模态层；内容层级主要依靠间距、分隔线和表面色。

## 6. 8pt 布局系统

`4 / 8 / 16 / 24 / 32 / 48 / 64 / 96`

- 手机水平边距 24px；小屏 20px；平板阅读列居中。
- 主要触控目标至少 48×48px，彼此间距至少 8px。
- 固定底栏必须为正文预留 `safe-area + 88px`，不得遮挡内容。
- 一屏只有一个主动作。返回、来源和设置不得与主动作竞争。
- 起卦、结果和历史页均可深链；返回必须保留问题、投币进度和阅读位置。

## 7. 核心产品结构

### 7.1 首页：静室

- 首屏仅包含当前时刻、一句邀请、可选问题和一个主动作。
- 问题可以留空；不以表单完成感压迫用户。
- 次级入口是“回看”，不是六十四卦大全。

### 7.2 起卦：参与而不是抽奖

- 默认入口为手动硬币录入或逐次投币；RNG 是明确标注的另一选项。
- 每次产生一爻，六爻结构从下向上生长；持续显示“第 n 爻”。
- 不用老虎机、爆闪、震屏或胜负音效。
- 触觉反馈只在一爻确认时轻触一次，且可关闭。

### 7.3 阅读：由结构进入文本

- 第一屏先确认卦序、卦名、上下卦与变爻，不立即倾倒全文。
- 固定顺序：结构 → 卦辞 → 大象 → 相关爻辞 → 小象 → 之卦 → 来源。
- 原文、编辑导读、现代译意必须有稳定且不同的标签层级。
- 每层允许跳过或继续；动效不阻断点击。

### 7.4 结束：不强迫解释

- 不出现必填“写下你的理解”。
- 只提供两个动作：“留在这里”和“私密保存”。保存也不要求追加文字。
- 不出现“再算一次”作为高强调 CTA，避免刷结果循环。

### 7.5 回看：时间而不是吉凶

- 以日期、问题片段、卦象和是否有变爻构成历史条目。
- 回看先显示当时内容，再允许用户选择性添加后记。
- 不做准确率、好运指数或预测命中统计。

## 8. 动效与声音

- 微交互 160–240ms；页面推进 280–360ms；禁止 500ms 以上的装饰性等待。
- 只动画 `opacity` 与 `transform`；每屏最多 1–2 个关键运动元素。
- 六爻显现从底部向上，保持因果与空间连续。
- “夜墨 → 暖纸”使用 320ms 交叉淡入，表达从仪式进入阅读，而非炫技。
- 所有动效必须可打断，并完整支持 reduced motion；降低动态后直接切换状态。
- MVP 默认无背景音乐；未来声音也必须默认关闭并可单独控制。

## 9. 可访问性与质量门槛

- 正文对比度 ≥4.5:1；大字与非文字图形 ≥3:1。
- 支持系统文字放大，经典文本不得截断。
- 屏幕阅读顺序与视觉阅读顺序一致；卦象提供完整文本描述。
- 所有动作具备 pressed、focus、disabled 状态；按压反馈不改变布局尺寸。
- 验收至少覆盖 375px、小/大手机、平板竖横屏、最大动态字体与 reduced motion。

## 10. 品牌辨识度测试

去掉 Logo 后，用户仍应能通过以下组合认出产品：

1. 夜墨进入暖纸的语义转场；
2. 准确且可解释的上下卦结构；
3. 原文—译意—来源的编辑层级；
4. 断线、连线和余白构成的布局节奏；
5. 不逼迫用户得出结论的结束方式。
